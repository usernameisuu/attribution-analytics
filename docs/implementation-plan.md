## 顺序与完成条件

1. 确定性分析：类型化结果、加法/LMDI/Shapley、两个冻结样例、可追溯的模拟；通过数值及边界检查。
2. 工程与接口：FastAPI、PostgreSQL 模型及迁移、账号和业务线权限、会话快照、分析与模拟 API；远程验证真实数据库事务。
3. 工作台：React/TypeScript 三栏布局、大盘、历史会话、贡献瀑布图、指标树和模拟；与真实 API 联调。
4. 数据与异步：版本化导入、真实明细数据、持久队列、幂等、租约、SSE、跨轮范围和恢复。
5. 探索与验证：DeepSeek、持久预算账本、假设、统计与独立 Linux 沙箱、事件及历史检索；在线累计预算 25 元，增加前向用户说明。
6. 完整输出：历史估计、收益区间、报告三格式、批注发布、站内订阅和审计管理。
7. 集成交付：远程部署、锁定依赖及镜像、完整 AC01～AC19、浏览器与导出检查、性能及备份恢复。

## 检查规则

- 本机仅运行不安装依赖的源码与纯函数轻量检查，禁止借此启动本地业务环境。
- 每一项完成以代码及实际检查记录为准；未配置模型、数据库、runner 的功能不能标成已验证。
- 精确样例分解不能冒充统计检验或真实因果发现；界面显示实际能力状态。
- 远程环境就绪后安装依赖、生成锁文件、迁移和端到端测试；目前尚无远程地址或密钥。
